# Dashboard

New to Sage? See the [[Sage guide]] and its tutorial.

Open tasks across the vault, soonest due first:

```view
type: tasks
source: "task-todo:"
columns: [task, file, due, priority]
```

Notes with an active status:

```view
type: table
source: "[status:active]"
columns: [file, status, tags, modified]
```
