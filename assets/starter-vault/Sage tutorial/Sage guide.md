# Sage guide

Documentation and a hands-on tutorial for **Sage**, a native Markdown notes app that works directly on an Obsidian-style vault. Every page is a plain note in this sample vault, so the guide is also something to practise on: follow its links, search it, rename it, query it.

> [!tip] New to Sage?
> Start the tutorial at [[01 Welcome]]. It takes about half an hour, and every step asks you to try something in the app. Your progress is the task [[finish-the-sage-tutorial]].
