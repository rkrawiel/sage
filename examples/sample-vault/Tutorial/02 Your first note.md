# Your first note

In this step you create a note in a new folder, write some Markdown, and see how saving works.

## Try it: create a note

1. Press `Ctrl+P` to open the **command palette**.
2. Type `Playground/My first note`. No note has that name, so the palette offers **Create note**. Press `Enter`.
3. Sage creates the `Playground` folder and the note, and opens it.

> [!info] Untitled notes
> `Ctrl+N` is the other way to make a note: it creates `Untitled.md` (or `Untitled 1.md`, …) in the vault root. You can name it later with `F2`, see [[09 Rename, move and delete]].

## Try it: write

Type, or paste, this into the new note and watch the preview follow:

```markdown
# My first note

Sage saves **by itself**, about a second and a half after I stop typing.

## Things to try

- *italic*, ~~struck out~~ and `code`
- ==a highlight==
- a numbered list:
  1. one
  2. two

> [!tip] A callout
> Callouts are quotes with a kind.
```

There is no save button. Autosave writes the note 1.5 s after your last keystroke, and `Ctrl+S` saves at once if you are impatient.

## Try it: find in the note

1. Press `Ctrl+F` and type `note`.
2. `Enter` jumps to the next match, `Shift+Enter` to the previous one.
3. `Esc` closes the find bar and leaves the match selected.

Keep **My first note** open: the next steps add to it.
